# isil-2026-ii
# Desarrollo de Aplicaciones Empresariales Avanzado

Repositorio académico con los proyectos y actividades desarrollados
durante el curso de Desarrollo de Aplicaciones Empresariales Avanzado
de ISIL, periodo 2026-II.

## Contenido

Los proyectos abordan el desarrollo de aplicaciones empresariales,
la separación por capas, la persistencia de datos y la integración
entre servicios mediante APIs REST.

Se incluyen ejercicios de clase y evaluaciones prácticas relacionadas
con la gestión de pedidos e inventario.

## Tecnologías

- Java 21
- Jakarta EE y WildFly
- Spring Boot y Spring Data JPA
- SQL Server y H2
- Maven, JUnit y Mockito
